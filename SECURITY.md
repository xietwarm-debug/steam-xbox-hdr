# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** feature for this repository. Include the affected version, relevant platform details, and a minimal reproduction. Do not publish private screenshots, account IDs, or diagnostic files in a public issue.

## Scope

The helper processes local screenshot files and does not upload images or send telemetry. Security reports about path handling, file parsing, shortcut injection, or untrusted repository/build workflows are in scope.
